# Empower to Employ | Responsive Website
A responsive website showcasing Polk State College's Empower to Employ (ETE) program, developed as part of my Web Development course.

## Project Overview
This project was created to provide an accessible, informative, and easy-to-navigate website highlighting the ETE program, student experiences, community partnerships, and future career opportunities.
As a student in the program, I wanted to incorporate my own experiences while applying the web development and design skills I learned throughout the semester.

## Live Website
[Visit the website](https://autumnlheffner.github.io/empower-to-employ/)

## Website Pages
- **Home** — Introduction to the program, featured information, and events.
- **About ETE** — Program information, team members, and community partnerships.
- **Student Experiences** — Student activities, internships, field trips, and a filterable photo gallery.
- **Future & Careers** — Career pathways, certifications, and employment opportunities.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Project Features
- Responsive layouts for desktop, tablet, and mobile devices
- CSS Flexbox and Grid
- JavaScript-powered photo gallery filtering
- Accessible navigation and descriptive image alternative text
- Consistent branding and visual design
- HTML and CSS validation

## Skills Developed
Throughout this project, I gained experience in website planning, wireframing, responsive design, accessibility, troubleshooting, and website deployment.

## Disclaimer
This website was created as an educational project for my Web Development course at Polk State College. It is an independent student project and is not an official website of Polk State College or the Empower to Employ program.
